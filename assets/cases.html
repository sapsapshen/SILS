Scenarios · 场景方案

三种最常见的需求，我们怎么交付

下面三份方案都建立在教材里已经写出来的章节上——不是 PPT 上画的概念图。 每一份都写清楚：用到哪几章、交付什么、多久、多少钱。

说明：以下为可交付方案说明，不是已签约客户的案例，也不含任何客户数据。 我们不会拿不存在的客户给自己背书。需要真实交付记录时，请在试听之后再谈这一点。

案例一 · 客服通话质检

教材对应：智能客服质检 — AI 能从一通客服电话中分析出什么 周期 3–4 周 ¥49,800 起

典型起点

质检靠人工抽听，覆盖率不到 5%；同一个问题不同人打分不一致；想知道"客户到底为什么不满意"却没有结构化数据。

我们做什么

  • ASR 转写 + 说话人分离，先拿到可分析文本
  • 用你们的质检标准做评分维度（本书的评分标准写法可直接套）
  • 一条通话输出结构化结论：问题类型、情绪走向、违规点、可引用原句
  • 抽样人工复核，算出与人工判断的一致率

交付物

  • 可跑通的质检流水线（部署在你们环境）
  • 评分标准文档 + 提示词与模型配置
  • 一致率测评报告（这是能不能上生产的关键数字）
  • 半天交接培训
¥49,800 起 / 单场景 含 200 通样本调优 超出样本按 3 元/通计 前置条件：你们提供脱敏通话样本与人工标注基准

案例二 · 产线巡检 Agent

教材对应：产线巡检 Agent — 用 Penguin Harness 快速开发与优化 周期 4–6 周 ¥69,800 起

典型起点

有摄像头和巡检制度，但异常靠人盯；换了新产线就要重写规则；想要 Agent 自己判断，又怕它乱下结论。

我们做什么

  • 把巡检规程拆成 Agent 可执行的判定链
  • 用教材里的自进化/评估闭环做迭代：观察 → 评估 → 采纳 → 回滚
  • 设定"不确定就不下结论"的兜底，异常升级到人
  • 按你们现场数据跑一轮离线评估

交付物

  • 巡检 Agent 与其判定规则（可回滚版本）
  • 离线评估集与评分脚本
  • 上线判定阈值与人工复核流程
  • 团队带练：你们的人能自己改规则
¥69,800 起 / 单产线 含 2 轮评估迭代 多产线按 30% 递减 前置条件：现场影像样本与巡检规程文本

案例三 · 企业知识问答助手

教材对应：实现一个企业知识问答助手 周期 2–3 周 ¥29,800 起

典型起点

文档散在网盘和群里，新人反复问同样的问题；直接上大模型又答得似是而非，说不清依据。

我们做什么

  • 文档清洗与切片，建立可检索的知识库
  • RAG 链路 + 强制引用原文出处
  • 答不出来就说答不出来（这比答错便宜得多）
  • 用 50 条真实问题做验收集

交付物

  • 可用的问答入口（内网部署）
  • 知识库更新流程（文档改了怎么同步）
  • 验收集与命中率报告
  • 管理员后台：看问了什么、答得怎么样
¥29,800 起 / 单知识域 含 500 份文档接入 增量文档按 2 元/份 前置条件：可提供文档与 50 条真实提问
提交需求，24 小时内回复 看服务包与报价区间
