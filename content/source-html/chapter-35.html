主流 LLM 评测

选模型时最容易犯的错，是拿公开榜单当结论。榜单衡量的是「模型在标准题集上的表现」，而你要回答的是「模型在我的业务上是否够用」。两者相关，但不等价。这一章给出一套可以在半天内跑完、结论能被复核的评测方法。

先分清三种评测

评测的目的不同，做法也完全不同。混在一起谈，就会出现「榜单第一但线上不可用」的落差。

  • 能力评测：模型会不会做某类题。用公开基准或自建题集，看的是上限。
  • 场景评测：模型在你的业务数据上是否达标。用真实分布的测试集，看的是下限。
  • 系统评测：接上检索、工具、审核之后，整条链路是否稳定。看的是延迟、失败率与成本。

选型阶段先做能力评测缩小范围，再用场景评测做最终决定，系统评测放到上线前。跳过第二步，是项目返工最常见的原因。

公开基准怎么看

公开基准适合做粗筛，不适合做验收。下面几个是常见的选择，使用时要知道它们各自测的是什么。

基准主要测什么使用时要注意
C-Eval / CMMLU中文知识与学科能力题目偏考试风格，与业务表达差异大
MMLU英文多学科知识对中文场景解释力有限
GSM8K / MATH数学推理看推理链是否稳定，不只看最终答案
HumanEval / MBPP代码生成通过率受提示格式影响明显
IFEval指令遵循与产品里的格式约束最接近

看榜单时有三个细节值得追：版本号是否对应你拿到的权重、评测用的是零样本还是少样本、分数是否带了置信区间。只报一个点估计的榜单，样本量往往不足以区分相邻两名。

用 EvalScope 跑一次本地评测

EvalScope 是 ModelScope 生态里的评测框架，优点是配置化、支持本地模型与 API 模型，结果可以落成结构化文件。下面是最小可用的一条命令。

pip install evalscope
evalscope eval \
  --model Qwen/Qwen2.5-7B-Instruct \
  --datasets ceval \
  --limit 200 \
  --work-dir ./eval-out

三个参数值得解释。--limit 先小样本跑通链路，确认没问题再放开全量；--work-dir 会保存逐题结果，方便复查错题；模型名要写到具体版本，不要用 latest 之类的别名。跑完之后先看错题分布，再看总分——总分相同、错题类型不同的两个模型，在你的场景里可能完全不同。

自建场景测试集

场景测试集不需要很大，但必须来自真实分布。经验值是每个关键任务 100 到 300 条，覆盖高频、长尾与对抗样本三类。构建顺序如下。

  • 从线上日志或工单里抽样，保留原始表达，不要改写得更「标准」。
  • 给每条样本写一份参考答案，并标注容错范围（哪些差异可以接受）。
  • 至少两人独立标注，分歧样本单独仲裁，记录仲裁理由。
  • 切出 20% 作为保留集，调提示词时不得使用。

如果数据不能出域，就在本地跑开源模型；如果需要对比闭源 API，只上传脱敏后的样本，并确认服务条款允许。

评分器：别只用一个指标

生成式任务的评分最容易失真。建议同时保留自动指标与人工抽检，两者不一致时以人工为准。

  • 抽取类任务用字段级精确率与召回率，空值单独统计。
  • 分类类任务用混淆矩阵，重点看业务最在意的那个错误方向。
  • 生成类任务用「要点覆盖 + 事实错误 + 格式合规」三项 rubric，人工按 1 到 5 分打分。
  • Agent 类任务用任务完成率、工具调用正确率与越权率，越权率必须单列。

自动指标可以用模型做裁判，但裁判模型必须与参评模型不同族，并且要用人工标注的子集校准一次。裁判与被评模型同源时，分数会系统性偏高。

把结果写成一张能决策的表

评测报告的价值在于支持决策，不在于罗列分数。建议每个候选模型一行，列出下面几列，并在最后写一句结论。

列含义
模型与版本可复现的唯一标识
场景指标主指标的均值与置信区间
关键错误最不能接受的那类错误的发生率
推理成本单次调用的 token 与金额，或本地显存占用
延迟P50 与 P95，而不是平均值
结论可用、有条件可用、不可用

常见坑

  • 数据污染：测试集题目出现在训练语料里，分数会虚高。用新近样本并做去重。
  • 提示词不对等：给 A 模型精心调过提示词，给 B 模型用默认模板，比较没有意义。
  • 采样参数不一致：温度、top_p、最大长度不同，结果不可比。
  • 样本量太小：几十条样本的差异可能只是噪声，至少要看置信区间。
  • 只看平均分：平均值会掩盖长尾失败，而长尾往往才是线上事故的来源。
  • 忽略版本漂移：API 模型会在不通知的情况下更新，评测结论要标注日期并定期复跑。

评测不是一次性动作，而是一条持续运行的流水线。把测试集、评分脚本与结果报告一起放进仓库，下一次换模型时，你只需要重跑一遍。
